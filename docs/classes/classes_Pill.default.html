check

  • check(x, y, c): void

    check Starting from the given cell, scans outward in all 4 directions (up/down/left/right) for a run of 4 or more same-colored cells (matching both pill halves and viruses). If a run of 4+ is found, clears it, pops any viruses it contained, and awards points for them.

    Parameters

    • x: number

      Column of the cell that was just placed/locked

    • y: number

      Row of the cell that was just placed/locked

    • c: string

      The cell's color letter ("r"/"b"/"y")

fall

  • fall(): void

  • Method

    fall After a match has been cleared, finds every pill half left floating over an empty cell (including halves whose other half already fell away and is now a lone piece) and drops each of them down, one row at a time, until they land - then re-checks for any new matches and re-runs itself in case that causes further pieces to fall.

    Returns void

    • Defined in classes/Pill.ts:196

move

  • move(): void

  • Method

    move

    Ticks the pill one cell further in its fall direction every second, as long as it isn't locked. Once it reaches the bottom row or the cell below it is occupied, it locks into the board, checks both halves for matches, and triggers any resulting fall.
